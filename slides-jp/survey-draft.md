# つかみ(1〜2分)

- 太陽は最後どうなるのか、という素朴な問いから入る
- 答え:白色矮星。太陽質量を地球サイズに圧縮した「燃え尽きた星」
- [常識を立てる] 風船は冷やすと萎む — 圧力は熱から生まれるから
- 星も同じ理屈で支えられている。核融合の熱が重力に対抗している
- [常識を壊す] ならば、燃え尽きた星は冷えて潰れるはず
- でも白色矮星は、宇宙の年齢より長く、潰れずに残る
- 熱がないのに、何が太陽質量を地球サイズに押し止めているのか?
- 答えは「電子の不思議な振る舞い」— 量子力学が星を支えている
- → 本題:量子力学 × 天体物理 × 流体力学の交差点へ

# ステージ1:普通の星はなぜ潰れないのか(3〜5分)

- 風船の例を星に拡張:重力と熱的ガス圧のバランス
- 静水圧平衡の概念(数式は最小限、図で)
- 核融合の役割:熱を絶えず補給することで圧力を維持し続ける
- フィードバック構造:熱が冷めれば圧力が下がり、星は縮もうとする
- → ここまでは「圧力 = 熱」の古典的な世界。次のステージでこの常識が破綻する

# ステージ2:燃え尽きるとどうなるはずか(2〜3分)

- 燃料が尽きる = 熱供給が止まる
- 普通の論理だと「冷えて潰れる」はず
- でも実際の白色矮星は安定に存在してる … なぜ?

# ステージ3:量子力学の登場(5〜7分)

- パウリの排他律(電子は同じ席に入れない)
- 詰め込むと電子は嫌でも高い運動量を持つ
- これが温度に依存しない圧力を生む = 縮退圧
- ここを「席取りゲーム」みたいなアナロジーで掴ませると強い

# まとめと次回予告(1〜2分)

- 白色矮星は「量子統計が支える星」
- 「でも、この支えにも限界がある」「もっと重い星はどうなるのか」
- → 次回:チャンドラセカール限界と中性子星・ブラックホール
